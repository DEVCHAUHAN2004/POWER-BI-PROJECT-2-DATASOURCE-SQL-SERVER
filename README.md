# Men's Fashion Brand Analytics Dashboard

## 📊 Power BI Business Intelligence Project

An interactive Power BI dashboard designed to analyze men's fashion brands across **discounts, profitability, product variety, and average sales price**.

### 🔗 Live Dashboard

[**View Interactive Power BI Dashboard →**](https://app.powerbi.com/groups/c665ef11-dba6-437f-9444-f47cf7dc9c09/reports/a66f386c-e374-4374-82b9-db3d038c333a/e483ef8442ed047d011c?experience=power-bi)

---

## 📌 Project Overview

This project focuses on analyzing men's fashion brand data using **Microsoft Power BI**.

The dashboard transforms raw brand-level data into meaningful visual insights that can help understand:

- Brand discount strategies
- Profitability across brands
- Product variety
- Average sales price
- Top-performing brands
- Lower-performing brands

The report is designed as a business-oriented dashboard where key comparisons can be understood quickly by stakeholders.

---

## 🎯 Business Objectives

The dashboard aims to answer the following questions:

1. Which brands offer the highest average discounts?
2. Which brands have the highest average profit percentage?
3. Which brands have the largest product variety?
4. Which brands have the highest average sales price?
5. Which brands appear at the lower end of the profitability analysis?
6. How do different brands compare across pricing, discount, variety, and profitability?

---
